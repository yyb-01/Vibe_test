# 정수 탄도 reference — 구현 경계

명세 B.3/B.4의 엔진 독립 기준 연산을 구현한다. 현재 게임의 발사·피격 경로에
연결하지 않았으며, 이 모듈만으로 전투 기능이 완료된 것은 아니다.

## 구현

`fixed_math.*`는 signed int64 두 값의 곱을 32bit limb로 정확히 보관한 뒤 양의
int64로 나눈다. signed 128bit 중간 값 범위를 벗어나지 않는 int64 곱 전체를
처리하며, 최종 결과가 int64 범위 밖이면 `LimitExceeded`다. 반올림은 nearest,
정확히 절반이면 even이다. INT64_MIN의 절댓값·부호 반전도 unsigned로 처리한다.
정수 제곱근은 libm 없이 nearest로 계산한다. 정수 입력의 제곱근에는 반정수 tie가 없다.
분자 인자/분모를 `std::gcd`로 약분하고 64bit에 들어가는 곱은 일반 정수 나눗셈을
사용한다. 약분은 값·부호·반올림 규칙을 바꾸지 않는다.

`ballistics::free_flight`는 균일한 바람·중력·항력 계수에서 한 번의 1/(240×divisions)s
explicit midpoint(RK2)를 계산해 새 상태를 반환한다. 위치는 μm, 속도는 μm/s다.
divisions 기본값은 1이며 1/2/4/8만 허용한다.
네 번째 인수 `fraction`은 해당 분할 시간의 Q0.24 비율(0..2²⁴)이다.
기본값 2²⁴는 기존 전체 step과 같고, 충돌 후에는 남은 비율을 전달할 수 있다.
0은 입력 검증 후 원래 상태를 반환한다. midpoint와 최종 적분 모두 같은 시간
비율을 사용하며, 최종 위치만 선형 보간해 짧은 시간을 흉내내지 않는다.
1/2 비율과 다음 divisions의 전체 step은 항력·중력에서도 동일하다.
시간을 임의로 나눈 두 번의 RK2가 한 번의 전체 RK2와 같다는 보증은 하지 않는다.
항력은 공기 상대 속도로 계산한다. 계수 `dragPpt`는 `rho*Cd*A/(2*m)`를
μm⁻¹ 단위로 바꾸고 10¹²배해 양자화한 값이다. 0이면 무항력이다.
현재 한 step에서 Cd는 상수이며, Mach LUT/공간 변화 날씨를 대신하지 않는다.

입력·midpoint·결과를 검사한다. 위치 축별 ±8km, 속력 2,000m/s, 풍속 120m/s,
중력 크기 100m/s², `dragPpt` 0..10,000 범위다. 마지막 두 값은 이 reference의
산술 입력 한도이며 승인된 ammo/weather cook 범위를 뜻하지 않는다.
실패하면 입력 상태는 그대로다. 정수 범위를 넘거나 속력 한도를 넘는 결과는 거절한다.
잘못된 입력은 `InvalidRequest`, 유효한 입력에서 나온 midpoint/결과가 위치·속력
한도를 넘는 경우는 `LimitExceeded`로 구분한다.

`BulletBlock<8>`은 명세의 SoA 필드와 align64/576B 레이아웃을 컴파일 검사한다.
현재 integrator는 단일 scalar Flight를 처리하며 이 배열을 SIMD로 실행하지 않는다.

`ballistic_collision.*`는 정적 AABB와 점 선분의 연속 교차를 계산한다.
entry/exit의 분수 비교에는 넓은 곱 대신 연분수를 사용하며, 교차 여부를 판정한
후에만 첫 접촉 시각을 Q0.24 nearest-even으로 양자화한다. 1mm 벽이나 양자화보다
얇은 간격을 끝점 overlap으로 놓치지 않는다. 시작점이 내부이면 TOI=0이다.
`BoxHit`는 이탈 시각 `exitFraction`, 바깥 법선 `exitNormal`, 실제 이탈 여부
`exits`도 반환한다. 구간이 내부에서 끝나면 exits=false이며 끝점에서 바깥으로
나가는 경우는 true다. 모서리 동률은 x/y/z 순서다. 이 시각은 Q0.24로 양자화되고
선분 끝으로 잘리므로 그 차이를 닫힌 volume의 전체 두께로 사용하지 않는다.
정확한 `entryRatio`/`exitRatio`도 보존한다.
구·capsule·OBB·triangle sweep, 반경·회전·움직이는 표적은 아직 지원하지 않는다.

`box_penetration.*`는 정적·직선 점 경로의 동일 AABB 진입/이탈을 에너지 장부에
연결한다. 시작점은 체적 밖 또는 경계여야 한다. 실제 출구가 선분에 없으면
`energy`를 비워 반환하며, 남은 체적을 짧은 벽으로 간주하지 않는다. 반경/곡률로
확대한 broadphase box를 여기에 전달하면 안 된다.
정확한 교차 비율에서 `시작점 + Q(변위×비율)`로 μm 좌표를 얻고, 두 점 사이
거리를 portable wide 제곱합·정수 sqrt로 nearest 반올림한다. 좌표·길이 양자화의
총 오차는 2.24μm 이하이며 실제 양의 chord가 0으로 반올림되면 1μm로 보존한다.
접선·단일점 접촉은 에너지를 소모하지 않는다. 경로가 calibration 범위를 넘으면
기존 `penetrate`가 정지시킨다. 임의 두께나 maxPath로 경로를 축소하지 않는다.
이는 완전한 volume 경로 질의이며 아직 시간 진행·감속·도탄 실행 루프는 아니다.

`penetration_transit.*`는 실제 경로와 상수 재료 저항으로 통과 시간 계획을 구한다.
진입 에너지 손실을 먼저 속도에 반영하고 잔여 에너지 예산에서 이탈 속도를 구한다.
일정한 저항력 모델의 `2×path/(entrySpeed+exitSpeed)`를 Q0.24 substep 단위로 계산한다.
여러 substep보다 긴 duration도 그대로 보관하며 현재 tick으로 잘라내지 않는다.
에너지 소진/보정 범위 밖은 출구 시간 없음으로 반환한다. 이는 전체 에너지·시간
계획이며, 벽 내부 정지 지점이나 시간별 상태를 아직 실행하지 않는다. 재료 내부는
직선·상수 저항 모델이고 공기 항력·중력은 제외한다. 출구로 즉시 teleport하거나
계획된 흡수량을 시간이 경과하기 전에 피해로 확정하는 데 사용하면 안 된다.

`transit_progress.*`는 성공한 관통 계획과 절대 경과 시간에서 속도·이동 거리·누적
흡수량을 구한다. 속도는 진입/이탈 속도의 시간 보간이며, 상수 저항의 경로는
소모한 운동에너지 비율로 계산한다. 무저항이면 시간 비율을 사용한다. 이 순서는
정수 반올림 뒤에도 거리와 흡수량의 단조성을 유지한다. 이전 sample을 누적해서
적분하지 않아 같은 절대 시각은 호출 간격과 무관하게 같다.
진입 손실은 elapsed=0의 누적 흡수량에 포함한다. 상위 사건 처리는 누적 값의 차이를
한 번만 적용해야 한다. 계획/질량/경로/시간의 일관성을 검사하고, 정확한 duration에
도달했을 때만 exited를 표시한다. 이 조회 함수 자체는 위치 이동이나 피해를 적용하지 않는다.

`volume_transit.hpp`의 `start_volume`은 진입 경계의 Flight와 출구를 포함하는 ray에서
관통 상태를 만든다. ray 방향이 속도와 μm 양자화 범위에서 일치하는지 확인한다.
확정된 통과 경로가 없으면 값을 반환하지 않는다. 이를 통과 허용으로 해석하지 않는다.
`advance_volume`은 저장한 경과 시간에서 이어서 위치·속도·흡수량을 갱신하고,
소비 시간과 남은 시간을 별도로 반환한다. 출구에 도달한 상태를 다시 호출하면
새 흡수량/소비 시간이 0이다. 시작 상태의 absorbedUj는 진입 손실이며 이후 반환값은
그 호출의 증가분이다. 같은 옛 상태 재실행의 중복 제거는 상위 저장 사건의 책임이다.
이 상태는 내부 권위 데이터다. 네트워크/저장 데이터를 구조체로 직접 복원해서
생성 검증을 우회하면 안 된다. 점 탄환·단일 정적 volume 모델이며, 실제 projectile의
수명/거리 제한은 아래 `advance_volume_projectile`, 출구 이탈과 잔여 시간은
`resume_volume`에 연결했다. 접촉에서의 자동 진입 선택과 겹친 layer 시간 진행은 남아 있다.

`advance_volume_projectile`은 점 탄환의 관통 상태를 Projectile 장부에 연결한다.
현재 substep에서 소비한 시간 비율을 보관하고 경계를 모두 소비했을 때만 age를
증가시킨다. 1,440 substep에서 Expired로 정지한다. 관통 거리는 최초 진입 거리와
절대 진행 거리에 일회성 4μm 반올림 여유를 더해 상한으로 기록한다. 호출을 나눠도
여유를 중복 가산하지 않는다. 2.5km를 넘는 경우 마지막 허용 경과 시간을 이분 탐색해
Range로 정지한다. 이때 실제 진행한 시간/흡수량만 반환한다.
종료 상태 재호출은 새 시간·흡수량을 만들지 않는다. 관통 중 Flight/질량/거리 장부의
불일치는 거절한다. terminal Projectile은 속도가 0이고 관통 snapshot은 정지 직전 값이다.
유한 반경의 narrowphase, 접촉에서 관통으로의 자동 전환, 겹친 layer 처리는 남아 있다.
확인된 출구의 장애물/잔여 시간 처리는 별도 `resume_volume`에서 실행한다.

`ballistic_energy.*`는 μJ 장부다. 질량 mg/속도 μm/s에서 운동에너지를 계산하고,
실제 교차 경로와 보정된 저항으로 관통 비용을 구한다. 경로가 보정 범위 밖이면
완전히 정지시키며 maxPath로 잘라 관통시키지 않는다. 도탄 에너지 유지율과
표면/몸/파편 분배는 UNORM16으로 받아 총량을 보존한다. 몸 경로 확인과
도탄 확률 판정은 호출자의 책임이며 재료 이름으로 수치를 추정하지 않는다.

`velocity_response.*`는 속도 벡터의 제곱합에서 μJ 에너지를 직접 계산한다.
속력 sqrt를 먼저 반올림하지 않는다. `limit_energy`는 Q0.32 공통 속도 배율을
이분 탐색하여 양자화된 잔여 운동에너지가 주어진 예산을 넘지 않게 한다.
성분별 nearest-even 반올림 후 다시 에너지를 계산하며, 예산과 실현 가능한 속도의
차이는 표면 흡수량에 포함한다. 예산 0은 정지한다.
`reflect_axis`는 승인된 AABB 면의 축 법선으로 반사한 뒤 같은 제한을 적용한다.
접선/바깥으로 나가는 속도, 영 법선·다축 법선은 거절한다. 도탄 발생 확률·입사각
정책·거칠기·표면 이탈 offset·재접촉 처리는 이 응답 함수의 외부 책임이다.
현재 `advance_barriers`의 정지 에너지는 이 벡터 장부와 일치하도록 연결했다.
승인된 정적 축 반사의 반복 접촉은 `advance_reflections`에 연결했다.
탄약·입사각·seed 기반 도탄 gate와 에너지 표는 `advance_reflections`에 연결했다.
관통 시간 진행은 `advance_volume_projectile`, 출구 이후 재개는 `resume_volume`에 연결했다.

## 실행 검증

`./scripts/build.ps1`의 `fixed integer math`, `ballistic scalar reference`,
`ballistic continuous box collision`, `ballistic energy conservation` 그룹:
부호/반올림/overflow/INT64_MIN, 1,000개 넓은 곱, 제곱근 경계,
1초 자유낙하 오차 ≤0.1mm, 900m/s 등속 1초, 정지 공기에서 감속,
공기와 같은 속도에서 항력 0, 바람에 의한 가속, 대칭성·잘못된 입력·실패 원자성.
추가로 BigInt 기반 넓은 곱의 독립 예상값, 1mm 벽·평행·역방향·경계 접촉,
Q0.24로는 구별되지 않는 비충돌 간격, 연속 레이어·보정 범위 초과·최대 정수
에너지·분배 총량 보존을 검사한다.
이탈 검증에는 정·역방향, 내부 정지/내부 끝점, 정확한 출구 끝점, 경계에서 즉시
이탈, 모서리 동률을 포함한다.
관통 연결 검증은 Q0.24보다 얇은 1μm 벽, 극소 양의 chord와 단일점 접촉의 구분,
출구 미확인, 3-4-12 대각선, ±8km 대각선 wide 제곱합, 범위 초과 정지를 포함한다.
속도 응답은 전량 유지/소진, 1/4 에너지, 여러 유지율, 최대 속력·질량, 잘못된
법선과 에너지 예산, 정지 충돌 장부의 이중 반올림 회귀를 검증한다.
관통 시간은 무저항 등속, 진입 손실 후 등속, 상수 감속, 역방향, 관통 불가,
보정 경로 초과, 1μm 경로의 양의 소요 시간을 검사한다.
시간 진행은 독립적인 중간 시점 예상값, 120개 시점의 단조성·에너지 보존,
누적 흡수량 차이의 합, 진입 손실·이탈 시각과 잘못된 계획/경과 시간을 검증한다.
상태 재개는 120 substep의 실제 위치, 분할 호출 동일성, 이탈 후 재호출, 남은 시간의
자유비행, 출구 미확인·방향 불일치·변조 상태 거절과 입력 불변성을 검사한다.
발사체 연결은 관통 중 6초 만료·사거리 직전 정지, 분할 호출의 동일한 거리 상한,
terminal 재호출, 시간 과소비·발사체/관통 상태 불일치 거절을 검증한다.

# 겹친 layer 경로와 에너지 계획

`layer_paths`는 정적 직선 점 경로와 확장하지 않은 AABB를 조회한다. 입력은 고유
SurfaceKey 순서이며 결과는 Q0.24 TOI, layerId, SurfaceKey 순서다. bodyId=0은 독립
재질이고, 같은 nonzero bodyId는 하나의 canonical 조직 layerId를 공유해야 한다.
같은 몸의 겹침/맞닿음은 양자화 전 비율로 합치며 공기 간격·다른 몸·장갑은 보존한다.
장기 교차는 별도 조회한다. tangent/점 접촉은 조직 두께를 만들지 않는다.

`LayerPath.complete`가 false이면 시작이 내부이거나 출구가 확인되지 않은 부분 경로다.
이때 pathUm을 전체 두께로 사용하면 안 된다. `layer_energy`는 모든 경로가 완전할 때만
기존 `penetrate` 장부를 순서대로 적용하고, 정지 뒤 재질에 에너지를 배정하지 않는다.
프로파일은 권위 측에서 제공하며 누락/중복/범위 오류는 miss에서도 거절한다.
반환값은 기하/에너지 계획이며, 탄환을 출구로 이동시키거나 피해를 적용하지 않는다.
겹친 재질에서의 시간 진행, 공중 접촉 선택과 실제 wound 적용은 아직 연결되지 않았다.
