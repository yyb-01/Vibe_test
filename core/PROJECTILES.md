# 정적 장애물 발사체 실행

`advance_barriers`는 기존 정수 자유비행·연속 박스 충돌·운동에너지 계산을 연결한다.
한 번에 1/240초를 진행하므로 권위 60Hz tick에서 4번 호출한다. 입력 상태를 복사해
결과를 반환하며, 검증 실패 시 원본은 변하지 않는다. 아직 실제 발사 승인/저장 경로에
연결하지 않았고, 피해나 탄약을 변경하지 않는다.

## 동작 계약

- `shotId`는 0이 아니어야 한다. 질량은 1..1,000,000mg, 반경은 0..100,000μm다.
- 균일 대기에서 최대 속력·바람을 고려한 가속도 상한을 구한다. 곡률 오차가 1mm
  이내가 되도록 1/2/4/8로 분할한다. 8분할로도 안 되는 profile은 `LimitExceeded`다.
  런타임 투입 전에 cook/승인 경로에서 거절해야 한다.
- `Barrier` 목록은 고유한 `(surface, collider, triangle)` 키의 오름차순이다.
  surface/collider 0, 중복·역순 키, 잘못된 박스는 거절한다. 같은 Q0.24 접촉 시각은
  이 키 순서로 판정한다. 먼저 찾은 박스에 즉시 반환하지 않고 나머지도 검증한다.
- `first_barrier`의 선택적 `departing` 키는 해당 확장 박스의 정확한 면 경계에서
  바깥으로 향하는 선분만 억제한다. 내부·접선·정지·재진입에는 적용하지 않는다.
  다른 surface/triangle은 같은 collider여도 계속 검사한다. 도탄 후 0.1mm offset을
  이동할 때도 이 질의를 사용해야 다른 얇은 장애물을 건너뛰지 않는다.
  이탈 좌표가 반올림으로 박스 내부에 있으면 억제하지 않으므로, 호출자는 검증된
  접촉 법선/면 좌표로 출발점을 확정해야 한다. 현재 정지 루프는 departing을 쓰지 않는다.
- 반경과 곡률 상한만큼 박스를 확장한 보수적 판정을 사용한다. 곡선이 직선 선분
  밖의 얇은 장애물에 닿는 경우를 놓치지 않는다. 박스 모서리에서는 실제보다
  일찍 정지할 수 있다. 정확한 swept-sphere/triangle 좁은 단계 판정은 아직 없다.
- 첫 접촉에서 정지하고 `BarrierImpact`에 shotId·표면 키·접촉 위치·시각·에너지를
  반환한다. 이미 정지한 상태를 다시 tick하면 추가 impact가 없다. 같은 옛 입력을
  재실행하는 것의 중복 제거는 상위 사건 저장 경로의 책임이다.
- 수명은 최대 1,440 substep(6초), 이동 거리는 최대 2,500m다.
  거리 장부 `distanceUpperUm`은 선분 길이의 올림값에 곡률/반올림 여유를 더한
  상한이다. 잔여 거리로 TOI를 제한하고, 그 뒤의 장애물은 impact로 만들지 않는다.
  보수적 거리 상한 때문에 정확히 2,500m보다 조금 일찍 정지할 수 있다.
- 정상 입력에서 계산된 다음 위치/속도가 허용 범위를 넘으면 마지막 유효 위치에서
  `StopReason::Limit`로 정지한다. impact와 피해 에너지를 만들지 않는다.
  잘못된 원본 입력은 여전히 `InvalidRequest`이며 원본을 변경하지 않는다.
- 선형 O(n) 장면 조회이며 tick 경로에 새 컨테이너를 할당하지 않는다.
  대규모 월드에는 불변 BVH와 성능 검증이 필요하다.

## 검증

`./scripts/build.ps1`의 `projectile barrier loop`, `projectile curvature and radius`,
`projectile range limit`이 가까운 장애물 선택, 동률 키, 종료 후 재호출, 6초 만료,
2/8분할·한도 초과 profile, 굽은 경로의 얇은 천장, 반경, 잘못된 장면,
사거리 전/후 접촉과 2.5km 상한, 위치·속력 한계 정지와 잘못된 입력 구분을 검사한다.
관련 코어 전체 86그룹 통과.
`tests/surface_departure.cpp`는 경계 이탈·역방향·접선·내부·재진입과 0.1mm 이탈
구간의 1μm 장애물을 검사한다. 전체 도탄 반복 루프가 완료됐다는 의미는 아니다.

## 남은 통합

`advance_reflections`는 정렬된 `ApprovedReflection` 목록에 지정된 이상적인 축 반사를
실행한다. 승인 목록이 없는 표면은 기존처럼 정지한다. 클라이언트가 공급할 자료가
아니다. 선택적 `RicochetGate`가 있으면 탄약 허용, 입사각, 샷 난수를 접촉마다 검사한다.
gate가 없는 경로는 사전 승인된 이상적 반사 fixture용이다. production 호출자는
서버가 산출한 gate를 제공해야 한다.
정지 질의 결과의 입력 속도·법선에서 반사 속도와 흡수량을 구하고, 소비한 Q0.24
시간을 제외한 나머지를 다시 적분한다. 반환 impacts는 시간 순서의 고정 8칸 배열이다.
반사 이벤트는 흡수 에너지만 포함하고 다음 접촉은 잔여 에너지를 사용한다.
substep당 8회, 수명 동안 16회 접촉하면 마지막 접촉에서 남은 에너지를 소진하고
Limit로 정지한다. 입력 contacts가 이미 16이면 추가 접촉을 생성하지 않는다.

반사 위치를 확장 박스의 해당 면에 맞추고 0.1mm 바깥 방향 offset을 검사한다.
이 작은 공간 보정은 시간은 소비하지 않지만 이동 거리 상한에는 포함한다.
offset 안의 다른 장애물은 보수적으로 정지·흡수 처리하며 추가 반사는 하지 않는다.
map/range 한도를 넘는 offset도 중단한다. 한 tick 내 모든 작업은 사본에 수행한다.
`tests/reflection_loop.cpp`는 잔여 시간 이동·에너지 보존·왕복 재충돌·접촉 한도와
offset 중 1μm 장애물을 검증하며 기존 projectile 그룹에서 실행한다.

`resume_volume`은 확인된 관통 출구에서 같은 이탈 질의를 재사용하고 남은 substep을
`advance_reflections`로 진행한다. 원래 벽을 수명 전체에서 제외하지 않는다. 출구 직후
1μm 장애물은 이탈 구간에서 정지하고, 먼 장애물은 잔여 시간의 비행 질의에서 검출한다.
이탈 흡수량과 다음 충돌 에너지 장부는 구분한다. volume step의 absorbedDeltaUj는 호출자가
별도로 한 번 적용한다. 진입 전에 소비한 substep 접촉 수를 넘겨 잔여 접촉 한도를 공유한다.
출구 key/위치, 관통 완료 상태, 남은 시간, 접촉 수가 일치하지 않으면 거절한다.
반사 루프의 선택적 duration은 현재 substep의 마지막 구간이며 impact 시간은 전체
substep 기준을 유지한다. substep 경계를 마치면 수명이 한 번만 증가한다.
관통 출구로부터의 연결은 tests/volume_resume.cpp에서 이탈 장애물·후속 충돌·관통 손실을
포함한 에너지 보존·접촉 한도를 검증한다. 공중 충돌에서 관통 상태로 진입시키는 선택과
volume 내부에 겹친 layer 처리는 아직 연결하지 않았다.

`approve_ricochet`의 입사각 μ는 정수 속력으로 나눈 법선 속도를 UNORM16 nearest-even으로
양자화하며 `mu < cosThreshold`를 적용한다. 확률은 Q16 0..65536이고, 서버 seed·shotId·
전체 표면 키·수명 접촉 순번으로 표준 seed_seq/mt19937_64를 초기화한다. 엔진 출력의
상위 16bit를 직접 비교한다. 전역 RNG 상태나 uniform_distribution 구현에 의존하지 않는다.
잘못된 확률은 충돌이 없는 호출에서도 거절한다. 기존 ideal fixture와 별도로
`tests/ricochet_gate.cpp`가 경계값·반복 입력 재현성·실제 루프 승인/거절을 검사한다.

`ApprovedReflection.energyResponse`에 승인된 `RicochetPoint` 표를 전달하면 접촉마다
입력 에너지에서 확률과 유지율을 조회한다. 에너지 키는 비음수·엄격한 오름차순이며
확률은 0..65536이다. 표 범위 밖은 도탄을 승인하지 않는다. 보간은
`low + Q((high-low)*(energy-lowEnergy)/width)` 순서이며 signed nearest-even 나눗셈을
사용한다. 단일 점 표는 정확히 그 에너지만 허용한다. 표의 계수는 재료 이름에서
생성하지 않으며 외부 보정 데이터다. 표를 사용하는 rule에는 gate가 필요하다.
표는 해당 호출 동안 유효하고 변경되지 않아야 한다. 충돌이 없어도 잘못된 표를
거절한다. `tests/ricochet_curve.cpp`가 범위·보간·wide 곱·루프 적용을 검증한다.

Barrier 루프는 불투과/반사이며 공중 접촉에서 관통으로의 자동 진입 선택은 남아 있다.
별도로 시작한 관통의 시간 진행·출구 이탈·잔여 시간은 `resume_volume`까지 연결했다.
국소 손상 상태/입사각별 다차원 응답·거칠기, Mach LUT, triangle/BVH,
움직이는 history proxy, SIMD parity는 남아 있다. 원자적 탄약/내구도 소비는 발사 승인
경로에 구현했지만 승인 shot→이 발사체 루프→피해·사망·UE 연결은 남아 있다.
이 보수적 접촉 결과만으로 실제 캐릭터 피해를 확정하지 않는다.
